Privacy Policy

Last updated: November 20, 2026

ClipAgent is a private automation tool operated by the owner of the YouTube channel Dhaki Tiki Clip. It is used only by that owner, for that channel.

What Google data ClipAgent uses

With the owner's permission, ClipAgent uses the YouTube Data API to upload videos to the owner's own channel and to set their title, description, tags and publish time. It does not read, collect, sell or share any other person's data.

Storage

The sign-in token is stored only in the owner's private computer and in an encrypted secret of the owner's private code repository. No data is sent to anyone else.

Limited use

ClipAgent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
